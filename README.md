# ingridsolan.com.br

Portfólio de **Ingrid Sol'An**: Supervisora de TI, DevOps & Backend.

Site estático (HTML + CSS, sem build) publicado com GitHub Pages no domínio
**[ingridsolan.com.br](https://ingridsolan.com.br)** (arquivo `CNAME`).

A página explicativa do ResolveAI está neste repositório, na pasta
`ResolveAi/`, para ser publicada junto com o portfólio. Outros repositórios
não aparecem automaticamente como subpáginas deste domínio.

- [ingridsolan.com.br/ResolveAi/](https://ingridsolan.com.br/ResolveAi/): como funciona a IA do ResolveAI

Para adicionar outra página ao domínio, inclua os arquivos estáticos em uma
pasta deste repositório e crie um cartão na seção "Projetos" do `index.html`.
